# internal-error

A mistake of the compiler's own.

An error the compiler reports: the program doesn't build until it's fixed.

## Why

The compiler reached a state it doesn't expect: the program is fine, or its mistake was reported in a way the compiler then tripped over.

## How to fix

Report it (with the program, or the smallest one that shows it) at https://github.com/egoist/asuka/issues.
