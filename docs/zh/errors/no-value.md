# no-value

当作值使用、却不产生值的东西。

编译器报告的错误：修正之前程序无法构建。

## 原因

没有 `else` 的 `if`、最后一行不是表达式的代码块、调用不返回值的函数、`()` 和 `_` 都没有值可给。

## 如何修正

给 `if` 加上 `else`，让代码块以那个值结尾，或者改用会返回值的函数。

## 错误示例

```asuka
fn sign(n: int) -> int = if n < 0 { -1 }
```

## 正确示例

```asuka
fn sign(n: int) -> int = if n < 0 { -1 } else { 1 }
```
