# brace-placement

代码块的 `{` 要写在上一行的末尾。

编译器报告的错误：修正之前程序无法构建。

## 原因

一行在能结束语句的地方就会结束语句，所以单独一行的 `Row` 已经是一个完整的调用，下一行的 `{` 会变成另一个独立的代码块。Asuka 只有一种读法，因此要求花括号写在代码块开始的那一行。

## 如何修正

把 `{` 移到上一行末尾：`fn f() {`、`Row {`、`if x {`。

## 错误示例

```asuka
fn greet() -> string
{
  return "hi"
}
```

## 正确示例

```asuka
fn greet() -> string {
  return "hi"
}
```
