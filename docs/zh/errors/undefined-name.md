# undefined-name

在使用的地方没有任何声明的名称。

编译器报告的错误：修正之前程序无法构建。

## 原因

一个名称的含义来自作用域里的声明：局部变量、参数、所在类型的成员、包里的声明，或者导入带进来的名称。拼错的名称、没有导入的其他包里的名称，以及在没有值的地方使用的 `self` 都不属于其中任何一种。

## 如何修正

修正拼写（消息会给出相近的名称），导入声明它的包，或者声明它。

## 错误示例

```asuka
fn double(count: int) -> int = cuont * 2
```

## 正确示例

```asuka
fn double(count: int) -> int = count * 2
```
