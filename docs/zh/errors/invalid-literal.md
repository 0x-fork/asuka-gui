# invalid-literal

写法不正确的数字、颜色、时长或转义。

编译器报告的错误：修正之前程序无法构建。

## 原因

字面量有固定的写法：颜色是十六进制的 `#rgb`、`#rgba`、`#rrggbb` 或 `#rrggbbaa`；时长的单位是 `ms`、`s`、`min` 或 `h`；转义必须是 Asuka 认识的（`\n`、`\t`、`\u{…}` 等）。编译时生成的值（图标的标记、模式）也必须能解析。

## 如何修正

按消息所说，用它的某种写法来写这个字面量。

## 错误示例

```asuka
let brand = #12345
```

## 正确示例

```asuka
let brand = #123456
```
