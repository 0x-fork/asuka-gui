# int-overflow

超出所属类型范围的整数字面量。

编译器报告的错误：修正之前程序无法构建。

## 原因

每种整数类型都有自己的范围：`int` 是 64 位，范围是 −9223372036854775808 到 9223372036854775807；`u8` 是 0 到 255，`i8` 是 −128 到 127，`u64` 是 0 到 18446744073709551615。超出类型范围的字面量不可能是这个类型的值，无符号类型也没有负数。

## 如何修正

换一个范围内的数，改用更宽的类型（`u16`、`int`、`u64`）或 `float`；需要超出 64 位的精确整数时，用 `std/bigint` 的 `BigInt`（`BigInt.parse("9223372036854775808")!`）。

## 错误示例

```asuka
let big = 9223372036854775808
let level: u8 = 300
```

## 正确示例

```asuka
let big: u64 = 9223372036854775808
let level: u16 = 300
```
