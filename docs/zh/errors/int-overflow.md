# int-overflow

超出 64 位范围的整数字面量。

编译器报告的错误：修正之前程序无法构建。

## 原因

`int` 是 64 位的，范围是 −9223372036854775808 到 9223372036854775807，超出这个范围的字面量不可能是 `int`。

## 如何修正

换一个更小的数，或者使用 `float`；需要超出 64 位的精确整数时，用 `std/bigint` 的 `BigInt`（`BigInt.parse("9223372036854775808")!`）。

## 错误示例

```asuka
let big = 9223372036854775808
```

## 正确示例

```asuka
let big = 9223372036854775807
```
