# type-mismatch

值的类型和期望的类型不同。

编译器报告的错误：修正之前程序无法构建。

## 原因

每个值都只有一个类型，而接收它的地方（参数、字段、写了类型的 `let`、返回值、`if` 的各个分支）规定了是哪个类型。Asuka 不会自动转换：`int` 不是 `float`，数字也不是字符串。

## 如何修正

给出期望类型的值，或者显式转换：`float(n)`、`int(x)`、`"{n}"`。

## 错误示例

```asuka
let count: int = "three"
```

## 正确示例

```asuka
let count: int = 3
```
