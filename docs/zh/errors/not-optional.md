# not-optional

对一定有值的值使用了可选类型的运算符。

编译器报告的错误：修正之前程序无法构建。

## 原因

`??`、`?.`、`!`、`if let` 和 `??=` 是给可能为 `none` 的值用的。用在不可能为 `none` 的值上，它们什么也不做，这通常说明类型和代码设想的不一样。

## 如何修正

去掉这个运算符，或者在声明处把值改成可选类型（`int?`）。

## 错误示例

```asuka
fn shown(count: int) -> int = count ?? 0
```

## 正确示例

```asuka
fn shown(count: int?) -> int = count ?? 0
```
