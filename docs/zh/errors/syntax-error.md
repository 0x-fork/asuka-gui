# syntax-error

解析器在这里期望的是别的内容。

编译器报告的错误：修正之前程序无法构建。

## 原因

解析器逐个读取 token，而这里读到的 token 不能出现在这个位置：比如运算符后面缺了值，括号或花括号没有闭合，或者两条语句写在同一行却没有用 `;` 分隔。

## 如何修正

看消息里的“expected …, found …”：补上它期望的内容，或在它指出的位置闭合未闭合的部分。一行里靠前的错误可能会掩盖后面的错误，所以先改第一个。

## 错误示例

```asuka
fn total(a: int, b: int) -> int {
  return a +
}
```

## 正确示例

```asuka
fn total(a: int, b: int) -> int {
  return a + b
}
```
