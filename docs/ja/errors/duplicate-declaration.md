# duplicate-declaration

同じ場所で 2 回宣言された名前。

コンパイラーが報告するエラーです。直すまでプログラムはビルドできません。

## 理由

名前は宣言された場所で 1 つのものだけを指します。パッケージのトップレベル、型のメンバー、関数のパラメーター、拡張、パターンのどれでも同じです。2 回宣言すると、どの使用箇所も曖昧になります。特定のプラットフォーム用のファイル（`tray_linux.asuka`）とすべてのプラットフォームが持つファイルの両方で宣言することもできません。

## 直し方

どちらかの名前を変えるか、不要なほうを削除します。

## 誤った例

```asuka
fn label() -> string = "a"
fn label() -> string = "b"
```

## 正しい例

```asuka
fn label() -> string = "a"
fn otherLabel() -> string = "b"
```
