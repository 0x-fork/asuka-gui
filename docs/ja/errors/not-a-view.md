# not-a-view

ビューのあいだにある、ビューではない値。

コンパイラーが報告するエラーです。直すまでプログラムはビルドできません。

## 理由

本体や要素のブロックに置けるのは要素とコンポーネントです。数値や文字列は、テキストを表示する要素で表示します。

## 直し方

要素の中で表示します（`Text("{n}")`）。

## 誤った例

```asuka
component Answer {
  Column {
    42
  }
}
```

## 正しい例

```asuka
component Answer {
  Column {
    Text("42")
  }
}
```
