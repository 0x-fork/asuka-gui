# not-supported

言語がまだ対応していないもの。

コンパイラーが報告するエラーです。直すまでプログラムはビルドできません。

## 理由

解析はできても、まだ実装されていない書き方がいくつかあります。ジェネリックなコンポーネント、必要な要素のない画面、コンパイラーがまだ変換できない一部の式です。代わりに使えるものをメッセージが示します。

## 直し方

メッセージが示す代わりの書き方を使います。ジェネリックなコンポーネントには、`View` やクロージャーの prop を使います。

## 誤った例

```asuka
component Box<T>(value: T) {
  Text("box")
}
```

## 正しい例

```asuka
component Box(value: string) {
  Text(value)
}
```
