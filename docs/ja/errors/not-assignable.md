# not-assignable

変えられないものを変えている。

コンパイラーが報告するエラーです。直すまでプログラムはビルドできません。

## 理由

変えられるのは `var`、状態、それらのフィールドや要素です。`let` は定数（コンポーネントでは読むものから導かれる値）、パラメーターは呼び出し側のもので、メソッドが自身の値を変えられるのは `mut fn` のときだけです。

## 直し方

`var`（または `state`）にするか、`let` が読むものを変えるか、メソッドを `mut fn` と宣言します。

## 誤った例

```asuka
fn countdown() -> int {
  let n = 3
  n -= 1
  return n
}
```

## 正しい例

```asuka
fn countdown() -> int {
  var n = 3
  n -= 1
  return n
}
```
