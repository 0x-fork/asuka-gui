# no-such-operator

ほかの言語にはあって Asuka にはない演算子。

コンパイラーが報告するエラーです。直すまでプログラムはビルドできません。

## 理由

Asuka は、ほかの書き方と同じ意味になる演算子を省いています。`++` と `--` は `+= 1` と `-= 1`、三項演算子 `?:` は値として使う `if` です。比較を連ねることもできません。

## 直し方

`x += 1`、`if a { b } else { c }`、`a < b && b < c` と書きます。

## 誤った例

```asuka
fn count() -> int {
  var n = 0
  n++
  return n
}
```

## 正しい例

```asuka
fn count() -> int {
  var n = 0
  n += 1
  return n
}
```
