# reserved-name

言語自身が使っている名前。

コンパイラーが報告するエラーです。直すまでプログラムはビルドできません。

## 理由

この位置ではすでに意味を持つ名前があります。`peek` は追従せずに読むこと、`style` はすべての要素のスタイルのリスト、`pressed` などのインタラクション状態はすべてのビューのバリアントです。宣言すると、言語の本来の意味が隠れてしまいます。

## 直し方

別の名前にします。

## 誤った例

```asuka
fn peek() -> int = 1
```

## 正しい例

```asuka
fn first() -> int = 1
```
