# not-a-value

値が入る場所で使われた型、パッケージ、メソッド。

コンパイラーが報告するエラーです。直すまでプログラムはビルドできません。

## 理由

型は値の種類の名前、パッケージは宣言の集まりで、メソッドは呼び出す対象の値を必要とします。どれも、渡したり保存したりできる値ではありません。

## 直し方

その型の値を作る（`Point(x: 1, y: 2)`）か、パッケージのメンバーを使うか、メソッドを呼び出します。

## 誤った例

```asuka
struct Point {
  x: int
  y: int
}

let origin = Point
```

## 正しい例

```asuka
struct Point {
  x: int
  y: int
}

let origin = Point(x: 0, y: 0)
```
