# missing-return

結果を返す関数が、結果なしで最後まで到達しうる。

コンパイラーが報告するエラーです。直すまでプログラムはビルドできません。

## 理由

`-> T` と書いた関数は、すべての経路で `T` を返します。コンパイラーは経路をたどるので、`else` のない `if` や、何も返さない `match` の分岐は、値のない経路になります。

## 直し方

すべての経路で値を返すか、関数を `return` で終えます。

## 誤った例

```asuka
fn sign(n: int) -> int {
  if n < 0 { return -1 }
}
```

## 正しい例

```asuka
fn sign(n: int) -> int {
  if n < 0 { return -1 }
  return 1
}
```
