# argument-count

呼び出しの引数が多すぎる、または少なすぎる。

コンパイラーが報告するエラーです。直すまでプログラムはビルドできません。

## 理由

呼び出しでは、既定値のないパラメーターすべてに値を渡し、パラメーターの数より多くは渡しません。case のペイロード、イベントの値、ハンドラーのパラメーターも同じように数えます。

## 直し方

関数の宣言どおりに渡します。省略できるのは既定値のあるパラメーターだけです。

## 誤った例

```asuka
fn add(a: int, b: int) -> int = a + b

let sum = add(1)
```

## 正しい例

```asuka
fn add(a: int, b: int) -> int = a + b

let sum = add(1, 2)
```
