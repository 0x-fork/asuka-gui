# int-overflow

64 ビットに収まらない整数リテラル。

コンパイラーが報告するエラーです。直すまでプログラムはビルドできません。

## 理由

`int` は 64 ビットで、範囲は −9223372036854775808 から 9223372036854775807 です。範囲外のリテラルは `int` になれません。

## 直し方

小さい数にするか、`float` を使います。大きな数を正確に扱うには `std/decimal` を使います。

## 誤った例

```asuka
let big = 9223372036854775808
```

## 正しい例

```asuka
let big = 9223372036854775807
```
