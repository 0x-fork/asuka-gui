# int-overflow

型の範囲に収まらない整数リテラル。

コンパイラーが報告するエラーです。直すまでプログラムはビルドできません。

## 理由

整数型にはそれぞれ範囲があります。`int` は 64 ビットで −9223372036854775808 から 9223372036854775807、`u8` は 0 から 255、`i8` は −128 から 127、`u64` は 0 から 18446744073709551615 です。型の範囲外のリテラルはその型の値になれず、符号なしの型に負の数はありません。

## 直し方

範囲内の数にするか、より広い型（`u16`、`int`、`u64`）や `float` を使います。64 ビットを超える整数を正確に扱うには `std/bigint` の `BigInt` を使います（`BigInt.parse("9223372036854775808")!`）。

## 誤った例

```asuka
let big = 9223372036854775808
let level: u8 = 300
```

## 正しい例

```asuka
let big: u64 = 9223372036854775808
let level: u16 = 300
```
