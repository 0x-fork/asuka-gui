# test-parameter

asuka test が生成できない型のテストのパラメーター。

コンパイラーが報告するエラーです。直すまでプログラムはビルドできません。

## 理由

パラメーターのあるテストはプロパティテストです。`asuka test` はパラメーターの値を生成して実行し、失敗した入力を見つけられるかぎり単純な値まで縮小します。`--fuzz` はそれを JSON として保存し、以降の実行はそれを毎回読み込みます。生成できるのは整数、浮動小数点数、真偽値、文字列、bytes、時間の長さと、それらからなる配列、文字列をキーとするマップ、セット、オプショナル、struct、列挙型です。ビュー、クロージャー、ストアには生成できる値がありません。また、パラメーターは生成された値をそれぞれ受け取るので、デフォルト値は持てません。

## 直し方

テストが扱うものをデータ（ID、フィールドからなる struct）として受け取り、残りはテストの本体でそこから作ります。

## 誤った例

```asuka
test "runs anything" (f: fn() -> int) {
  expect(f() == f())
}
```

## 正しい例

```asuka
test "reversing twice" (xs: [int]) {
  expect(xs.reversed().reversed() == xs)
}
```
