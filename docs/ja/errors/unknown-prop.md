# unknown-prop

要素にないプロパティ、スロット、バリアント。

コンパイラーが報告するエラーです。直すまでプログラムはビルドできません。

## 理由

要素が受け付けるのは宣言したプロパティと、スタイルを受け付けるビューを表示する場合のスタイルプロパティです。スタイルにはスタイルプロパティしか書けません。綴りを間違えたプロパティが通ってしまうと、何も起きないまま見過ごされます。

## 直し方

既存のプロパティを使います（メッセージが提案します）。

## 誤った例

```asuka
component Title {
  Text("Hello") { colour: .red }
}
```

## 正しい例

```asuka
component Title {
  Text("Hello") { color: .red }
}
```
