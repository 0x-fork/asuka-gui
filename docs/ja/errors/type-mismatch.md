# type-mismatch

期待とは違う型の値。

コンパイラーが報告するエラーです。直すまでプログラムはビルドできません。

## 理由

値の型は 1 つで、それを受け取る側（パラメーター、フィールド、型を書いた `let`、戻り値、`if` の各分岐）がどの型かを決めます。Asuka は自動では変換しません。`int` は `float` ではなく、数値は文字列ではありません。

## 直し方

期待される型の値を渡すか、変換します（`float(n)`、`int(x)`、`"{n}"`）。

## 誤った例

```asuka
let count: int = "three"
```

## 正しい例

```asuka
let count: int = 3
```
