# invalid-literal

正しく書かれていない数値、色、時間、エスケープ。

コンパイラーが報告するエラーです。直すまでプログラムはビルドできません。

## 理由

リテラルには決まった形があります。色は 16 進の `#rgb`、`#rgba`、`#rrggbb`、`#rrggbbaa`、時間の単位は `ms`、`s`、`min`、`h`、エスケープは Asuka が知っているもの（`\n`、`\t`、`\u{…}` など）です。コンパイル時に作られる値（アイコンのマークアップ、パターン）も解析できなければなりません。

## 直し方

メッセージのとおり、決まった形のどれかで書きます。

## 誤った例

```asuka
let brand = #12345
```

## 正しい例

```asuka
let brand = #123456
```
