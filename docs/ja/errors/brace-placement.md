# brace-placement

ブロックの `{` は前の行の末尾に書く。

コンパイラーが報告するエラーです。直すまでプログラムはビルドできません。

## 理由

行は文を終えられるところで文を終えます。そのため、1 行に単独で書いた `Row` はそれだけで完結した呼び出しになり、次の行の `{` は別のブロックの始まりになってしまいます。Asuka の読み方は 1 通りしかないので、波括弧はブロックが始まる行に書くよう求めます。

## 直し方

`{` を前の行の末尾に移します（`fn f() {`、`Row {`、`if x {`）。

## 誤った例

```asuka
fn greet() -> string
{
  return "hi"
}
```

## 正しい例

```asuka
fn greet() -> string {
  return "hi"
}
```
