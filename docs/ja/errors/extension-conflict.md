# extension-conflict

型がすでに持つ名前、またはほかの拡張も追加する名前を追加する拡張。

コンパイラーが報告するエラーです。直すまでプログラムはビルドできません。

## 理由

拡張は名前を追加するだけで、置き換えはしません。そのため、メソッドの意味がインポートによって変わることはありません。2 つの拡張が同じ型に同じ名前を追加すると、呼び出すたびに曖昧になります。

## 直し方

メソッドの名前を変えるか、拡張を 1 つだけ残します。

## 誤った例

```asuka
extend string {
  fn count() -> int = 0
}
```

## 正しい例

```asuka
extend string {
  fn wordCount() -> int = fields().count()
}
```
