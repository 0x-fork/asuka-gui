# not-optional

必ず値がある値に、オプショナル用の演算子を使っている。

コンパイラーが報告するエラーです。直すまでプログラムはビルドできません。

## 理由

`??`、`?.`、`!`、`if let`、`??=` は `none` になりうる値のためのものです。そうならない値に使っても何も起きず、たいていは型がコードの想定と違っていることを示しています。

## 直し方

演算子を外すか、宣言でその値をオプショナル（`int?`）にします。

## 誤った例

```asuka
fn shown(count: int) -> int = count ?? 0
```

## 正しい例

```asuka
fn shown(count: int?) -> int = count ?? 0
```
