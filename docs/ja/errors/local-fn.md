# local-fn

ブロック内の関数が、ファイルの関数にしかないものを使っている。

コンパイラーが報告するエラーです。直すまでプログラムはビルドできません。

## 理由

ブロックの中で宣言した関数は、そのブロックの補助関数です。`pub`、ジェネリック、native、extern にはできず、引数は既定値なしで順番に受け取ります。

## 直し方

それらが必要なら、ファイルのトップレベルで宣言します。

## 誤った例

```asuka
fn pair() -> int {
  fn both<T>(x: T) -> [T] = [x, x]
  return both(1).count()
}
```

## 正しい例

```asuka
fn both<T>(x: T) -> [T] = [x, x]

fn pair() -> int {
  return both(1).count()
}
```
