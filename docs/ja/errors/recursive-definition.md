# recursive-definition

自分自身で定義された値やスタイル。

コンパイラーが報告するエラーです。直すまでプログラムはビルドできません。

## 理由

定数、`let`、状態は、読むものから計算されます。直接でも間接でも自分を読む値には、計算を始める最初の値がありません。自分を適用するスタイルは終わりません。

## 直し方

循環を断ちます。どちらかを、それを読み返さない値から計算します。

## 誤った例

```asuka
let width = height * 2
let height = width / 2
```

## 正しい例

```asuka
let width = 200
let height = width / 2
```
