# not-sendable

別のスレッドに渡せない値。

コンパイラーが報告するエラーです。直すまでプログラムはビルドできません。

## 理由

ワーカーに渡すもの、`spawn` から返すものは、値としてコピーされます。数値、文字列、配列、それらからなる struct です。クロージャー、ストア、ビュー、ネイティブオブジェクトは作ったスレッドのものです。

## 直し方

それを持つオブジェクトではなく、相手のスレッドが必要とするデータを渡します。

## 誤った例

```asuka
worker Runner {
  pub fn run(f: fn() -> int) -> int = f()
}
```

## 正しい例

```asuka
worker Runner {
  pub fn twice(n: int) -> int = n * 2
}
```
