# invalid-constant

コンパイル時に作られる値が、リテラルでないか解析できない。

コンパイラーが報告するエラーです。直すまでプログラムはビルドできません。

## 理由

いくつかの値は、コンパイル時に文字列リテラルから作られます。SVG アイコンはマークアップから、シェーダーのプログラムはソースからです。実行時に組み立てたテキストからは作れず、解析できないマークアップからは何も作れません。

## 直し方

リテラルそのものを渡し、解析できないとメッセージが示す部分を直します。

## 誤った例

```asuka
import std/svg

let icon = svg.Icon("<svg")
```

## 正しい例

```asuka
import std/svg

let icon = svg.Icon(r"""<svg viewBox="0 0 24 24"><path d="M12 3v12"/></svg>""")
```
