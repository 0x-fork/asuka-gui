# no-value

値として使われているが、値を生まないもの。

コンパイラーが報告するエラーです。直すまでプログラムはビルドできません。

## 理由

`else` のない `if`、最後の行が式でないブロック、何も返さない関数の呼び出し、`()`、`_` には、渡せる値がありません。

## 直し方

`if` に `else` を付けるか、ブロックを値で終えるか、値を返す関数を使います。

## 誤った例

```asuka
fn sign(n: int) -> int = if n < 0 { -1 }
```

## 正しい例

```asuka
fn sign(n: int) -> int = if n < 0 { -1 } else { 1 }
```
