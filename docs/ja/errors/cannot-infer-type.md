# cannot-infer-type

書かれた内容から値の型を判断できない。

コンパイラーが報告するエラーです。直すまでプログラムはビルドできません。

## 理由

型は値から推論されますが、`[]`、`[:]`、`none`、`.case` は自分の型について何も語りません。引数から型パラメーターがわからないジェネリックな呼び出しも同じです。

## 直し方

値を置く場所で型を書きます（`let ids: [int] = []`、`Type.case`、`f<T>(…)`）。

## 誤った例

```asuka
let ids = []
```

## 正しい例

```asuka
let ids: [int] = []
```
