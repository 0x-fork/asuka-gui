# pattern-type

値の型に一致しえないパターン。

コンパイラーが報告するエラーです。直すまでプログラムはビルドできません。

## 理由

`match`、`if let`、`catch` のパターンは、照合する型の値を表します。その型のリテラル、case の 1 つ、同じ長さのタプルです。別の型のパターンは決して一致しません。

## 直し方

値と同じ型のパターンを書きます。int なら `"one"` ではなく `1` です。

## 誤った例

```asuka
fn name(n: int) -> string = match n {
  "one" => "1"
  _ => "?"
}
```

## 正しい例

```asuka
fn name(n: int) -> string = match n {
  1 => "one"
  _ => "?"
}
```
