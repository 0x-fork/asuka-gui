# undefined-name

使われている場所で何も宣言していない名前。

コンパイラーが報告するエラーです。直すまでプログラムはビルドできません。

## 理由

名前の意味は、スコープにある宣言で決まります。ローカル変数、パラメーター、属している型のメンバー、パッケージの宣言、インポートで取り込んだ名前のいずれかです。綴りの誤り、インポートしていないパッケージの名前、値のない場所での `self` は、どれにも当てはまりません。

## 直し方

綴りを直す（近い名前をメッセージが提案します）か、宣言しているパッケージをインポートするか、宣言します。

## 誤った例

```asuka
fn double(count: int) -> int = cuont * 2
```

## 正しい例

```asuka
fn double(count: int) -> int = count * 2
```
