# unexpected-block

ブロックを取らない呼び出しのあとにあるブロック。

コンパイラーが報告するエラーです。直すまでプログラムはビルドできません。

## 理由

呼び出しのあとのブロックは、最後の引数（関数）か、要素のプロパティと子です。最後のパラメーターが関数でない関数や、struct、ストア、ワーカーは、値を括弧の中でしか受け取りません。

## 直し方

値を括弧の中で渡し、ブロックを外します。

## 誤った例

```asuka
fn twice(n: int) -> int = n * 2

let four = twice(2) {
  3
}
```

## 正しい例

```asuka
fn twice(n: int) -> int = n * 2

let four = twice(2)
```
