# syntax-error

パーサーがここで別のものを期待している。

コンパイラーが報告するエラーです。直すまでプログラムはビルドできません。

## 理由

パーサーはファイルをトークンごとに読み進めますが、ここで見つかったトークンはこの位置に来られません。演算子のあとに値がない、括弧や波括弧が閉じていない、`;` で区切らずに 2 つの文を 1 行に書いている、といった場合です。

## 直し方

メッセージの「expected …, found …」を読み、期待されているものを書くか、指摘された位置で開いているものを閉じます。行の前のほうの誤りが同じ行の後ろの誤りを隠すことがあるので、最初のものから直してください。

## 誤った例

```asuka
fn total(a: int, b: int) -> int {
  return a +
}
```

## 正しい例

```asuka
fn total(a: int, b: int) -> int {
  return a + b
}
```
