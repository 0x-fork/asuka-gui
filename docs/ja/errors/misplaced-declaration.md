# misplaced-declaration

その種類の宣言が置けない場所にある宣言。

コンパイラーが報告するエラーです。直すまでプログラムはビルドできません。

## 理由

場所ごとに置ける宣言が決まっています。ファイルは最初にインポート、そのあと型、関数、状態。struct はフィールドとメソッド。ストアは状態、let、fn、タスク、エフェクト。ワーカーは var、let、fn。列挙型は case が先で、定数とメソッドがそのあと。拡張はメソッドと定数です。

## 直し方

その種類が置ける場所に移すか、この場所で使える書き方にします（ワーカーでは `state` の代わりに `var`）。

## 誤った例

```asuka
worker Index {
  state count = 0
}
```

## 正しい例

```asuka
worker Index {
  var count = 0
}
```
