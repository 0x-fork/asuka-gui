# unterminated

文字列、コメント、エスケープが閉じていない。

コンパイラーが報告するエラーです。直すまでプログラムはビルドできません。

## 理由

文字列は同じ行の `"` で、ブロックコメントは `*/` で、`\u{…}` は閉じ波括弧で終わります。終わりがないと、ファイルの残りがすべてその一部として読まれてしまいます。

## 直し方

閉じてください。複数行にわたる文字列は `"""…"""` と書きます。

## 誤った例

```asuka
let greeting = "Hello
```

## 正しい例

```asuka
let greeting = "Hello"
```
