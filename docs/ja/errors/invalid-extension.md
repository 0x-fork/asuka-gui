# invalid-extension

拡張できないものの `extend`、または受け付けない形の `extend`。

コンパイラーが報告するエラーです。直すまでプログラムはビルドできません。

## 理由

拡張が追加できるのは名前のある型（組み込みでも宣言したものでも）です。関数型、タプル、interface には追加できません。ジェネリックな拡張の型パラメーターはその型のものであり、定数や static fn には呼び出し先となる名前付きの型が必要です。

## 直し方

名前のある型を拡張するか、代わりに関数を宣言します。

## 誤った例

```asuka
extend fn() -> int {
  fn twice() -> int = self() * 2
}
```

## 正しい例

```asuka
fn twice(f: fn() -> int) -> int = f() * 2
```
