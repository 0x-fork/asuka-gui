# not-callable

関数ではないものの呼び出し。

コンパイラーが報告するエラーです。直すまでプログラムはビルドできません。

## 理由

呼び出せるのは関数、クロージャー、メソッドだけです。値やフィールドは呼び出せず、interface、enum、C の型も名前を呼び出して作ることはできません。

## 直し方

関数を呼び出すか、値をそのまま使うか、列挙型の case を作ります（`Kind.name`）。

## 誤った例

```asuka
fn twice(n: int) -> int = n(2)
```

## 正しい例

```asuka
fn twice(n: int) -> int = n * 2
```
