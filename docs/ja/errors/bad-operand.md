# bad-operand

演算子が受け付けない値に使われている。

コンパイラーが報告するエラーです。直すまでプログラムはビルドできません。

## 理由

演算子ごとに受け付ける型があります。算術は同じ種類の数値（`int` と `int`、`float` と `float`）、ビット演算は整数、`[]` は配列、マップ、bytes、`==` は同じ型の値です。struct はメソッドから演算子を得ます（`fn add` が `+`）。

## 直し方

片方を変換する（`float(n)`）か、メソッドを使う（`a.concat(b)`）か、型に演算子のメソッドを追加します。

## 誤った例

```asuka
let rest = "hello" - "h"
```

## 正しい例

```asuka
let rest = "hello".slice(1, 5)
```
