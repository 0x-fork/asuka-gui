Make this app a stopwatch.

- The root component is `Stopwatch`, and the `app` block shows it.
- A text says `Elapsed: N s`, the whole seconds counted, 0 at first.
- A button titled `Start` starts counting a second at a time; while it
  counts, the button's title is `Stop`, and tapping it stops counting
  (the seconds counted stay).
- A button titled `Reset` sets the count back to 0.
