Make this app a search over fruits.

- The root component is `Fruits`, and the `app` block shows it.
- The fruits are Apple, Banana, Cherry, Date and Elderberry, each shown as
  a text, in that order.
- A text field with the placeholder `Search` filters them: a fruit shows
  while its name contains what's typed, ignoring case.
- When none matches, a text says `No results`.
